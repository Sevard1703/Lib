# Shahar kutubxonasi — Bilimlar olami

## Loyiha haqida
Ushbu loyiha shahar aholisi uchun mo‘ljallangan zamonaviy axborot-kutubxona veb-saytidir. Sayt orqali kitoblar katalogi, xizmatlar, tadbirlar, multimedia, kontaktlar va hujjatlarni ko‘rish mumkin.

## Maqsad
- aholiga qulay va zamonaviy kutubxona xizmatlarini taqdim etish;
- online katalog va qo‘llab-quvvatlovchi xizmatlarni yaratish;
- madaniy tadbirlar va ta’lim resurslarini yetkazib berish;
- HTML5, CSS3 va JavaScript yordamida to‘liq frontend tizimini yaratish.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Responsive layout
- Form validation
- Interactive modal windows
- Multimedia elements

## Ishga tushirish
1. `city-library` katalogiga kiring.
2. `index.html` faylini brauzerda oching.
3. Agar kerak bo‘lsa, server orqali oching, masalan:
   - Python: `python -m http.server 8000`
   - keyin brauzerda `http://localhost:8000` manzilini oching.

## Amalga oshirilgan funksiyalar
- bir nechta sahifali sayt tuzilmasi;
- asosiy menyu va mobil navigatsiya;
- kitoblar katalogi: qidiruv, filtr, saralash, modal oynalar;
- kutubxona xizmatlari va ish jadvali;
- tadbirlar sahifasi va ro‘yxatdan o‘tish formasi;
- multimedia sahifasi: rasmlar, audio va video;
- bog‘lanish sahifasi: ma’lumotlar, xarita va murojaat formasi;
- PDF hujjatlar va kerakli biznes ma’lumotlari;
- o‘zbek tilidagi umumiy dizayn va matnlar.
